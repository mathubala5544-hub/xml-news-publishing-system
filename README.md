# XML-Based News Publishing System

A web-based News Publishing System developed using XML and Oracle Database.

## Technologies Used
- Java Servlets
- JSP
- XML
- Oracle Database
- Apache Tomcat

## Features
- Admin Login
- Add News Articles
- Publish News
- View Published News

## Default Login
Username: admin  
Password: admin123

## How to Run

1. Install Java JDK
2. Install Apache Tomcat
3. Install Oracle Database
4. Import project into Eclipse
5. Run on Tomcat Server
